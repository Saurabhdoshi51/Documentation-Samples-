# 📑Before and After Examples

This page shows how the resource ID automation changes a DITA topic during the generation and cleanup stages.

The examples use the same topic so you can easily compare each stage.

## Example 1: Before Automation

Before running the script, the topic does not contain the resource ID generated by this workflow.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE topic PUBLIC "-//OASIS//DTD DITA Topic//EN" "topic.dtd">
<concept id="GUID-96C0B326-B7D-459-A82-C2DDF">
   
   <title id="GUID-96C0B326-B7D-459-A82-C2DDF" class="- topic/title "> Hydrogen-Sulfide (H2S) Modeling </title>
   <shortdesc class="- topic/shortdesc ">
</shortdesc>
   <conbody class="- topic/body  concept/conbody "> </conbody> </concept>
```

**What to notice:** The topic does not yet contain the `resourceid` element used by this workflow.

## Example 2: After Resource ID Generation

After running the XML-based automation, the topic contains a `resourceid` element with a generated `ux-context-string` value.

```xml
 <?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE topic PUBLIC "-//OASIS//DTD DITA Topic//EN" "topic.dtd">
<concept id="GUID-96026-B37D-459-AF82-2DDA13">
<title id="GUID-96026-B37D-459-AF82-2DDA13" class="- topic/title "> Hydrogen-Sulfide (H2S) Modeling </title><shortdesc class="- topic/shortdesc ">
</shortdesc>
<prolog class="- topic/prolog ">
<resourceid class="- topic/resourceid " id="GUID-A74BFB4C1F1811582C0" ux-context-string="DnU_HydrogenSulfideH2SModeling"/></prolog>
   <conbody class="- topic/body  concept/conbody "> </conbody> <p> </p></concept>
```

**What to notice:** The `resourceid` element and attribute have been inserted according to the configured naming pattern.
